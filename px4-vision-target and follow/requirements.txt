# Both pinned <2 / <5, not just floors: ros-humble-cv-bridge (apt) is a
# compiled extension built against Ubuntu 22.04's stock NumPy 1.x headers.
# NumPy 2.0 broke C-API ABI compat, so an unpinned `ultralytics` OR
# `opencv-python` install (neither has an upper bound on its own) resolves to
# NumPy 2.x today and cv_bridge dies at import with "AttributeError:
# _ARRAY_API not found" -- confirmed opencv-python>=5.0 forces numpy>=2 as a
# hard dependency, so the opencv-python bound has to move in lockstep with
# the numpy one. This must stay <2 / <5 in whichever single environment runs
# ros2_nodes/ -- don't try to isolate cv_bridge and ultralytics into separate
# envs, that just re-adds the apt-vs-pip problem one level up (you'd need
# --system-site-packages either way).
opencv-python>=4.9.0,<5
numpy<2
